星穹签到助手 v1.5.1 —— 使用说明
====================================

【它做什么】
启动《崩坏：星穹铁道》→ 等待并点击「点击进入」→ 等待并点击「点击领取今日补给 / 今日奖励」
→ 点一下屏幕确认 → 可选执行日常 → 关闭游戏 → 退出程序。
运行时屏幕左下角有一个步骤浮窗，显示 1/7 ~ 7/7 的当前进度。
签到成功/未弹窗/失败会保存截图，并可通过 OneBot v11 发到你的 QQ。

【界面】
左侧导航：首页 / 日常任务 / QQ 通知 / 定时签到 / 运行日志 / 设置 / 关于
· 首页：游戏状态、立即签到、签到选项
· 日常任务：签到成功后执行内置日常（邮件/委托/清体力/支援/无名勋礼/每日实训）
· QQ 通知：OneBot v11 私聊发送签到/日常结果和截图
· 定时签到：启用程序内定时，或创建 Windows 计划任务
· 运行日志：完整的签到过程日志
· 设置：游戏路径、窗口参数、OCR 参数
· 关于：作者信息与赞赏码

【第一次使用】
1. 双击「星穹签到助手.exe」。
2. Windows 会请求管理员权限，点「是」。
   （游戏 StarRail.exe 本身要求管理员，普通权限无法启动、也点不动。）
3. 程序会自动找到 E:\Star Rail Game\StarRail.exe；没有就点「浏览」手动选择。
4. 先手动登录一次游戏（让启动器记住账号），然后关闭游戏。
5. 回到首页点「立即签到」。签到成功后默认关闭游戏并退出程序。

【日常任务】
· 日常任务页勾选「签到成功后执行日常任务」。
· 内置日常：邮件、委托、拟造花萼按剩余开拓力清空、支援角色战斗、支援奖励、无名勋礼（奖励+任务一键领取）、每日实训 500 全领。
· 不需要安装任何外部程序；模拟宇宙、差分宇宙、货币战争、历战余响不在内置范围内。
· 不想清空开拓力，可在日常页取消「清空剩余开拓力」。
· 日常结束后按「签到后关闭游戏」选项决定是否关闭游戏。
· 即使签到失败（没有弹窗/已领取），只要开启日常，也会继续执行日常。

【QQ 通知】
· QQ 通知页勾选「启用 QQ 通知」。
· 填 OneBot API 地址（默认 http://127.0.0.1:3000）、Token（如有）、你自己的 QQ 号。
· 点「发送测试消息」确认能收到，再保存。
· 签到成功/失败/未弹窗和日常结束都会先发文字、再发截图。

【检查更新】
· 启动约 2.5 秒后自动检查 GitHub 仓库最新版本。
· 有新版本会弹窗显示更新内容和下载按钮，可直接前往下载。
· 「关于」页有「检查更新」按钮；「设置」里可以关闭启动时检查。
· 弹窗里勾选「跳过此版本」后，启动时不再提示该版本。

【每天定时】
· 程序内定时：定时签到页 →「设置定时…」→ 勾选启用、选时间与星期 → 保存。
  程序需要保持运行。
· 计划任务：同样在「设置定时…」里选好时间，回到定时签到页点「创建计划任务」。
  这样程序不运行也会每天自动签到；创建后程序内定时会自动关闭。
· 修改任务时间：先点「删除计划任务」，设置新时间后再点「创建计划任务」。

【失败怎么办】
· 日志：data\logs\app_日期.log，也可以在「运行日志」页直接看。
· 失败截图：data\screenshots\fail_日期时间.png，日志里会列出当前画面识别到的文字。
· 游戏必须已登录；遇到登录界面（要输账号密码）本工具不会处理。
· 游戏请使用「无边框窗口 / 窗口化」；独占全屏可能导致截图是黑的。
· 游戏窗口保持 16:9，推荐 1920×1080，并使用管理员身份运行，可以解决大部分问题。
